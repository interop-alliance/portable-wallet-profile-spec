Portable Wallet Profile for Portable Web Spaces v0.1

A companion profile to Portable Web Spaces (PWS) for portable digital wallets. It defines what a portable wallet needs from a PWS server (the server requirements a wallet checks before it trusts a server with an account) and how a portable wallet lays out its data on that server (the Space roles an account holds, its system collections and records, and the backup bundle an account is exported, restored, and moved with), so that a wallet written in any language can read, restore, and move an account written by another.

This is an experimental specification and is undergoing regular revisions.

This profile has two conformance targets. A server conforms to the server requirements half when it satisfies every requirement of Server requirements; nothing else in this profile binds a server. A wallet conforms when it follows the Wallet data conventions and depends on a server only through the server requirements half.

A server declares the first claim by listing this profile's persistent identifier in its PWS service description, as This profile's identifier describes.
